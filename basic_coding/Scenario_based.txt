🔥 CLASS & OBJECT BASED CODING QUESTIONS (VERY COMMON)
1️⃣ Basic Class Design

Question:
Create a Employee class with:
attributes: name, salary
method: get_annual_salary()

Input:
Employee("Ravi", 50000)

Output:
600000

2️⃣ Inheritance (CORE QUESTION)

Question:
Create a base class Vehicle with method start().
Create a child class Car that overrides start().

Expected behavior:

Vehicle().start() → "Vehicle started"
Car().start()     → "Car started"

3️⃣ Method Overriding + super()

Question:
Extend parent method but still call parent logic using super().

Hint:
Interviewers want to see if you know when to use super().

4️⃣ Abstract Base Class (VERY IMPORTANT)

Question:
Create an abstract class Payment with method pay(amount)
Implement CreditCardPayment and UPIPayment.

Input:
payment = CreditCardPayment()
payment.pay(1000)


Output:
Paid 1000 using Credit Card

5️⃣ Polymorphism (REAL USE)

Question:
Create multiple classes with same method name calculate_salary()
Call them in a loop without checking object type.

Interviewer checks:
do you rely on isinstance()? (bad)
or pure polymorphism? (good)

🧠 WHAT INTERVIEWERS REALLY CHECK

At 3 YOE, they want to see:
Can you design, not just code
Do you know why inheritance is bad sometimes
Can you explain trade-offs
Are you Pythonic or Java-in-Python

⚠️ HARD TRUTH
If you cannot comfortably write:
a base class
a child class
override a method
use super()
apply @property

👉 you will struggle in mid-level interviews.
